# Bundled fonts

The app ships two fonts in this directory and loads them into its own
process at startup (see `itgmania_library/library_fonts.py`). Nothing is
installed on the machine. The repository's code stays MIT; the fonts carry
their own terms, recorded here.

## Barlow Condensed

- Files: `BarlowCondensed-Light.ttf`, `BarlowCondensed-Regular.ttf`,
  `BarlowCondensed-SemiBold.ttf`, `BarlowCondensed-Bold.ttf`.
- Source: the Google Fonts repository, `ofl/barlowcondensed/`.
- License: SIL Open Font License 1.1. The full text ships beside the files
  as `OFL.txt` (Copyright 2017 The Barlow Project Authors).

## Wendy

- File: `wendy.ttf`.
- Source: `dafont.com/wendy.font`, classified "100% Free". No license text
  is shipped with the font, so none is bundled here; the source and its
  classification are recorded in this note instead.
